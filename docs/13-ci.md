# CI — HelpDesk BQ

## Backend (`Backend/.github/workflows/ci.yml`, Node 22)
`npm ci` → `npm run lint` → `npm run test:coverage` → `npm audit --audit-level=high`.
Roda em `pull_request` e `push` na `main`. Falha em: lint sujo, teste vermelho,
cobertura < 70% ou vulnerabilidade high/critical.

## Frontend (`Frontend/.github/workflows/ci.yml`, Node 22)
`npm ci` → `lint` → `test:coverage` (gate 80%) → `audit --audit-level=high`.
E2E Playwright fora do CI (repo isolado não orquestra PG); E2E é local contra
API + seed, mais 2 roteiros manuais (`tests/e2e/roteiro-manual.md`).

## Evidência
Último verde local: backend 24 suites / 160 testes; frontend 5 suites / 82 testes;
audits com 0 high/critical nos dois repos.
